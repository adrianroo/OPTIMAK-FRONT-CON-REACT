---

## Instalación y ejecución

### 1. Clonar o descargar el repositorio
 
Descarga el ZIP desde GitHub, descomprímelo y abre una terminal dentro de la carpeta resultante.

### 2. Instalar dependencias

```bash
npm install
```


### 3. Iniciar el servidor de desarrollo

```bash
npm run dev
```

La terminal mostrará algo similar a:


VITE v5.4.x  ready in 300 ms



### 4. Abrir en el navegador

Ve a **http://localhost:5173** 

---

## Cómo usar la aplicación

### Inicio de sesión

La pantalla de login acepta **cualquier usuario y contraseña** — no hay validación, Lo único que importa es elegir el rol

- Selecciona **Administrador** para entrar al panel de gestión completo.
- Selecciona **Operario** para entrar al flujo de producción 

Completa los tres campos (identificación, contraseña, rol) y haz clic en **INICIAR SESIÓN**.
